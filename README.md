# 🚀 DocuMind AI

An advanced AI-powered PDF chatbot built using Streamlit.

## 🔥 Features

* 📂 Upload PDF
* 🎤 Voice input
* 🤖 AI-based Q&A
* 🧠 Smart document understanding
* 💬 Chat interface
* 🌙 Dark UI

## 🛠️ Tech Stack

* Python
* Streamlit
* LangChain
* FAISS
* HuggingFace Embeddings

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
